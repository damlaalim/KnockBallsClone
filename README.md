# KnockBallsClone
Knock Balls Game clone developed in Unity.
# Levels
Each level contains three chapters. Dying in any chapter will return you to the first chapter of that level.<br>
<b>Level completion condition:</b> Use ammunition to knock all the boxes off the platform.
1. Fixed platforms feature flat boxes and exploding boxes. 
2. Fixed platforms that rotate around their own axis feature flat boxes, exploding boxes, and TNT boxes.
3. Platforms move either around their own axis or along the x-axis. There are two types of platforms.

# Elements
## Boxes
1. Flat Box: Falls off the platform when hit.
2. Fragile Box: Breaks into pieces when hit, and only one piece needs to fall to the ground to be destroyed.
3. TNT Box: Explodes when hit and blows up surrounding boxes.
   
## Platforms
1. Fixed platform
2. Rotating platform
3. Platform moving along the x-axis
